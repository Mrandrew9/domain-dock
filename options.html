Never auto-group

Tabs on these sites stay ungrouped. Subdomains are included: google.com covers Gmail and Docs, while mail.google.com covers only Gmail. Groups that already exist are not changed.

Backup

Your labels, tags, notes, rules, excluded sites and incident checklist live only in this browser, and Chrome deletes them if you remove DomainDock. Export a backup to keep them or move them to another computer.

The backup is a plain JSON file that lists the web addresses you labelled. Keep it somewhere private.

How labeling works

Open DomainDock, select + Label beside a tab, and save a memorable label, tags, or note. Find it later by typing any word or #shopping.

Page labels are saved against page URLs (Amazon product links are normalized to their product ID). They remain available when that page is reopened. They do not rename Chrome's actual tabs or inspect webpage content.

Privacy

Everything stays in Chrome's local extension storage. No analytics, external requests, cloud sync, or page-content access. A backup file is created only when you click Export backup. This extension requires the tabs permission to search tab titles and URLs, plus tabGroups and storage for grouping and labels.
